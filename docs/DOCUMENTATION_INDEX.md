## Updating Documentation

When changes are made to the project, update corresponding documentation:

### For Code Changes
- Update [DEVELOPMENT_CHECKLIST.md](DEVELOPMENT_CHECKLIST.md) if checklist changes
- Update [DELIVERY_SUMMARY.md](DELIVERY_SUMMARY.md) if deliverables change
- Update [API_REFERENCE.md](API_REFERENCE.md) if API changes

### For Configuration Changes
- Update [SETUP_DEPLOYMENT_GUIDE.md](SETUP_DEPLOYMENT_GUIDE.md)
- Update `.env.example`
- Update [README.md](../README.md) if applicable

### For New Features
- Add to [DEVELOPMENT_CHECKLIST.md](DEVELOPMENT_CHECKLIST.md)
- Add to [DELIVERY_SUMMARY.md](DELIVERY_SUMMARY.md)
- Add to appropriate guide (Animation, API, etc.)

### For New Projects
- Follow [PROJECT_COPYWRITING_GUIDE.md](PROJECT_COPYWRITING_GUIDE.md)
- Add to [PORTFOLIO_README.md](../PORTFOLIO_README.md) features
- Update [DEVELOPMENT_CHECKLIST.md](DEVELOPMENT_CHECKLIST.md)
